# Step 00 baseline task protocol

Audit date: 2026-10-21. No participants or production telemetry were available; this protocol records what should be measured in the first observed sessions and how to count it.

| Task | Observe | Baseline measure | Current evidence |
| --- | --- | --- | --- |
| Buyer: turn a need into a useful brief and first source-backed option | Whether user identifies the goal, constraints, source and missing facts; how often they correct the agent | Time to first useful artifact; correction count/type; completion and abandonment | Not observed; n=0. Repository evaluation is not usability evidence. |
| Buyer: explain the recommendation and choose a next action | Whether user can state fit, trade-off, uncertainty, owner and external consequence | Correct decision comprehension by criterion; wrong-action/confusion count; next-owner clarity | Not observed; n=0. |
| Seller: create or update product evidence and understand publication | Whether user distinguishes draft/private, review, publication and withdrawal | Task completion; source/claim correction effort; publication comprehension; useful response quality | Not observed; n=0. |
| Buyer/seller: handle consent, offer, approval and external handoff | Whether each party understands what is shared, exact terms, who acts next and outcome status | Boundary comprehension; stale/denied recovery; next-owner clarity; handoff outcome attribution | Not observed; n=0. |
| Any role: recover after missing, stale, denied, failed or uncertain state | Whether work and deep link survive and the user can resume safely | Recovery completion; duplicate action; lost-context report; time to resume | Not observed; n=0. |

## Collection rules

- Record participant role, task, environment, date, facilitator and count. Separate moderated task observations from telemetry.
- Capture task completion and actual correction/recovery events; do not convert opinion or a prototype click into purchase success.
- Report numerators/denominators and missing observations. With small samples, use findings to locate friction, not population conversion claims.
- Telemetry must exclude private briefs, budgets, raw source documents, credentials, and message content unless an approved collection purpose and policy exists.
- Add seller response usefulness as a structured, optional participant judgment and separately report objective response outcomes where available.

Baseline status: protocol defined; all user outcome measures unknown until collected. No target or success threshold is set without a business owner and an observed baseline.
