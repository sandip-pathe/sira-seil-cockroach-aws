# Customer-facing claim register

Status date: 2026-10-21. This register is a release control for marketing and in-product claims. “Supported wording” describes what current repository evidence allows; a claim is not approved for publication solely because it is written here. Legal, privacy, security, pricing, and commercial policy statements need their accountable owners.

## Review metadata required for each shipped claim

Store the approved string key, supporting route/code/test or policy record, responsible owner, environment, last verified date, next review trigger, allowed scope, and any required disclosure. Recheck when UI behavior, integrations, money flow, identity, data retention, provider, deployment or business policy changes. Missing evidence blocks the claim, not unrelated preparation work.
